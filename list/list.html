There are three type of list in Html

Description List (definitions)

Unordered Lists
Used for shows items with bullets
Ordered Lists
Used for shows items with numbers (1, 2, 3…)
Description List (definitions)
Used for terms and their descriptions

Ordered Lists

  1. First Element
  2. Second Element
  3. Third Element

Unordered Lists

  • First Element
  • Second Element
  • Third Element

Nested Lists

  • First Element
  • Second Element
    1. First Element
    2. Second Element
    3. Third Element
  • Third Element
